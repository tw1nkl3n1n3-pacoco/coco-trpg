# TRPG 로그 사이트

TRPG 세션을 기록해 두고, 같이 플레이한 사람들끼리 보고 고치는 로그 사이트예요.
오프라인 세션은 클로바노트 같은 음성 인식으로 뽑은 대사(txt)와 녹음 파일을, 온라인 세션은 코코포리아 로그(html)를 올려요. 녹음이 금지된 세션도 날짜만 남길 수 있어요.

- **로그 고치기:** 화자 고치기, 대사 나누기·합치기, 녹음 들으며 확인하기, 상황 묘사·주사위·핸드아웃·단락·고유명사 블럭
- **세션마다 자동 비밀번호:** 링크와 비밀번호를 같이 받은 사람만 로그를 보고 고칠 수 있어요. 들어올 때 내 인물을 고르거나, 외부인(읽기만)으로 볼 수 있어요
- **세션 페이지:** 개요, 플레이어·등장인물(인장), 회차 목록, 완주 도장
- **세션 후기:** 블로그처럼 굵게·색·소제목·사진을 넣어 쓰고, 후기만 따로 링크로 보낼 수 있어요. 다른 곳에 쓴 후기는 링크(+글 비밀번호 메모)로 붙여요
- **로그 댓글:** 대사마다 댓글·답글. 컴퓨터에서는 구글 문서처럼 오른쪽에 늘 보여요
- **이모티콘:** 관리자가 등록한 그림을 후기·댓글 어디서든 `:이름:`으로 써요
- **룰에 맞춘 테마** (인세인, D&D, 더블크로스), HTML 로그 내보내기, 링크 미리보기 이미지
- 여럿이 동시에 고쳐도 서로 덮어쓰지 않아요

데이터는 각자의 Firebase에 저장되고, 이 저장소에는 코드만 있어요.

## 내 사이트 만들기 (처음 한 번, 30분쯤)

필요한 것: **GitHub 계정**, **Google 계정**

### 1. 이 저장소 포크하기
이 페이지 오른쪽 위 **Fork** → **Create fork**.
사이트 주소는 `https://내아이디.github.io/저장소이름/` 이 돼요.

### 2. Firebase 프로젝트 만들기
1. [Firebase 콘솔](https://console.firebase.google.com)에서 **프로젝트 추가** (Google 애널리틱스는 꺼도 돼요)
2. **빌드 → Firestore Database → 데이터베이스 만들기** (위치는 `asia-northeast3 (서울)` 추천, 프로덕션 모드)
3. **빌드 → Authentication → 시작하기 → 로그인 방법**에서 **Google**과 **익명**을 켜기
4. **Authentication → 설정 → 승인된 도메인**에 `내아이디.github.io` 추가
5. (녹음 파일·후기 사진·이모티콘도 올리려면) **빌드 → Storage → 시작하기**
   Storage는 사용한 만큼 내는 **Blaze 요금제**여야 쓸 수 있어요. 무료 사용량이 있어서 소규모 모임이면 대부분 무료 범위 안이에요. 대사 로그와 글 후기만 쓸 거면 이 단계는 건너뛰어도 돼요 (녹음·사진·이모티콘 올리기만 안 돼요).
6. **프로젝트 설정(톱니) → 일반 → 내 앱 → 웹 앱(`</>`) 추가** → 나오는 `firebaseConfig` 값을 메모해 두기

### 3. 포크한 저장소에 내 설정 넣기
포크한 저장소 → **Settings → Secrets and variables → Actions → Variables 탭 → New repository variable** 로 두 개를 만들어요.

| Name | Value |
|---|---|
| `FIREBASE_CONFIG` | 2-6에서 메모한 값을 JSON 한 줄로 (아래 예시처럼 키에 따옴표) |
| `OWNER_EMAIL` | 관리자로 쓸 Google 이메일 |

`FIREBASE_CONFIG` 예시:
```
{"apiKey":"AIza...","authDomain":"내프로젝트.firebaseapp.com","projectId":"내프로젝트","storageBucket":"내프로젝트.firebasestorage.app","messagingSenderId":"123...","appId":"1:123...:web:abc..."}
```

### 4. 배포 켜기
1. 포크한 저장소 → **Actions** 탭 → **I understand my workflows, go ahead and enable them**
2. **Settings → Pages → Build and deployment → Source** 를 **GitHub Actions** 로
3. **Actions** 탭 → 왼쪽 **사이트 배포** → **Run workflow**
   몇 분 뒤 `https://내아이디.github.io/저장소이름/` 이 열려요.

### 5. 관리자로 로그인하고 보안 규칙 넣기
1. 사이트 맨 아래 **관리자 로그인** → 3에서 넣은 이메일의 Google 계정으로 로그인
2. **"보안 규칙을 새 버전으로 바꿔 주세요"** 창이 떠요 (처음엔 꼭 떠요)
3. **규칙 복사** → **Firebase 규칙 화면 열기** → 원래 내용을 전부 지우고 붙여 넣기 → **게시**
   DB 규칙(Firestore)과 녹음 저장소 규칙(Storage) 두 번 해요. 관리자 이메일은 자동으로 채워져 있어요.
4. 사이트를 새로고침해서 **⚙ 관리 → 보안 규칙 점검**이 둘 다 **✓ 최신**이면 끝!

### 6. 처음 설정
- **⚙ 관리 → 사이트 설정:** 사이트 이름·설명·아이콘, **내 닉네임**(여러 개면 쉼표로). 내 닉네임과 같은 플레이어는 세션마다 자동으로 '나'가 돼요
- **⚙ 관리 → 이모티콘:** 이름과 이미지를 올리면 사이트 어디서든 `:이름:`으로 써요 (Storage 필요)
- 메인 화면 **＋ 세션 올리기**로 첫 세션을 올려요

## 쓰는 법 요약

**세션 올리기** (메인 화면 ＋ 세션 올리기, 또는 세션 페이지의 ＋ 회차 올리기)
1. 오프라인 / 온라인
2. 이어서 하는 세션(완주한 세션은 안 보여요) / 새 세션
3. 오프라인: 클로바노트 txt + 녹음 파일(이름이 같으면 알아서 짝지어요) 또는 녹음 없음
   온라인: 코코포리아 방 메뉴 → 로그 출력으로 받은 html 또는 로그 없음
4. 확인하고 올리기

**같이 플레이한 사람에게 보내기**
세션 페이지 맨 아래 **세션 비밀번호 → 링크+비밀번호 복사**를 보내요. 받은 사람은 링크로 들어와 자기 인물을 고르고 비밀번호를 넣어요. 그 다음부터 로그 고치기·후기·댓글을 쓸 수 있어요. 비밀번호를 새로 만들면 예전 비밀번호로 연 사람은 다시 잠겨요.

**GM에게 후기 보내기**
후기 옆 🔗을 누르면 그 후기만 보이는 링크가 복사돼요. 이 링크는 비밀번호 없이 누구나 볼 수 있어요.

**완주 처리**
세션 페이지 ✎ 수정 → 완주에 체크하면 메인 화면에 완주 도장이 찍히고, 세션 올리기의 '이어서 하는 세션' 목록에서 빠져요.

## 업데이트 받기

원본 사이트가 업데이트되면 **⚙ 관리** 아이콘에 빨간 점이 생겨요.

1. **⚙ 관리 → 업데이트**에서 바뀐 내용을 확인하고 **업데이트하러 가기**
2. 열리는 내 저장소 페이지에서 **Sync fork → Update branch**
3. 몇 분 뒤 자동으로 다시 배포돼요

보안 규칙이 바뀐 업데이트라면 관리자로 들어왔을 때 규칙 안내 창이 다시 떠요. 5-3처럼 붙여 넣고 게시하면 돼요.

> 포크한 저장소의 파일은 직접 고치지 않는 게 좋아요. 고치면 업데이트할 때 충돌이 날 수 있어요. 개인 설정은 전부 Variables와 DB에 있어서 파일을 고칠 일이 없어요.

## 자주 묻는 것

- **비밀번호 없이 로그가 보이지 않나요?** 로그·녹음·핸드아웃·댓글은 Firebase 서버 규칙으로 잠겨 있어서, 비밀번호를 넣은 사람과 관리자만 볼 수 있어요. 세션 이름·룰·개요·캐릭터 이름은 목록에 보이도록 공개예요.
- **후기는 공개인가요?** 후기는 GM에게 링크로 보낼 수 있게 누구나 읽을 수 있어요. 링크 후기에 적은 글 비밀번호 메모도 마찬가지라, 다른 곳에도 쓰는 중요한 비밀번호는 적지 마세요. 후기를 쓰는 건 세션 비밀번호로 들어온 사람만 돼요.
- **'나'를 잘못 골랐어요.** 세션 페이지 등장인물 칸의 **바꾸기**로 다시 골라요. '나'는 브라우저마다 따로 기억해서, 다른 기기에서는 다시 골라야 해요.
- **다른 기기에서 내가 쓴 후기·댓글을 못 고쳐요.** 후기·댓글은 쓴 브라우저에서만 고칠 수 있어요. 관리자는 어디서든 고치고 지울 수 있으니 관리자에게 부탁해 주세요.
- **외부인으로 들어오면 뭐가 달라요?** 로그·후기·댓글을 읽기만 할 수 있어요. 화면에서만 막는 거라, 같이 플레이한 사람끼리 비밀번호를 나누는 걸 전제로 해요.
- **저장소가 공개인데 괜찮나요?** 저장소에는 코드만 있어요. Firebase 접속 값(apiKey)은 원래 공개돼도 되는 값이고, 실제 보호는 서버 규칙이 해요.
- **링크 미리보기 이미지가 안 바뀌어요.** 30분마다 자동 배포될 때 반영돼요. 카카오톡은 미리보기를 한동안 저장해 둬서 더 늦을 수 있어요.
- **배포가 실패했어요.** GitHub 쪽 일시 장애일 때가 많아요. 몇 분 뒤 **Actions → 사이트 배포 → Run workflow**로 다시 돌려 보세요.
