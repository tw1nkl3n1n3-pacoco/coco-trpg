# 코코 로그방

TRPG 세션을 기록해 두고, 같이 플레이한 사람들끼리 보고 고치는 로그 사이트입니다.
오프라인 세션은 클로바노트 같은 음성 인식으로 뽑은 대사(txt)와 녹음 파일을, 온라인 세션은 코코포리아 로그(html)를 올립니다. 녹음이 금지된 세션도 날짜만 남길 수 있습니다.

- **로그 고치기:** 화자 고치기(이미 있는 이름으로 바꾸면 세션 전체에서 합치기), 대사 나누기·합치기, 녹음 들으며 확인하기, 상황 묘사·주사위·핸드아웃·단락·고유명사 블럭
- **세션마다 자동 비밀번호:** 링크와 비밀번호를 같이 받은 사람만 로그를 보고 고칠 수 있습니다. 들어올 때 내 인물을 고르거나, 외부인(읽기만)으로 볼 수 있습니다
- **세션 페이지:** 개요, 플레이어·등장인물(인장), 회차 목록, 완주 도장. 녹음이 금지된 날은 로그 없이 날짜만 회차로 남깁니다
- **캠페인:** 여러 시나리오를 편으로 엮고(외전 포함), 캠페인 비밀번호 하나로 모든 편을 엽니다
- **세션 후기:** 블로그처럼 굵게·색·소제목·사진을 넣어 쓰고, 후기만 따로 링크로 보낼 수 있습니다. 다른 곳에 쓴 후기는 링크(+글 비밀번호 메모)로 붙입니다
- **로그 댓글:** 대사마다 댓글·답글. 컴퓨터에서는 구글 문서처럼 오른쪽에 늘 보입니다
- **이모티콘:** 관리자가 등록한 그림을 후기·댓글 어디서든 `:이름:`으로 씁니다
- **룰에 맞춘 테마** (인세인, D&D, 더블크로스), HTML 로그 내보내기, 링크 미리보기 이미지
- **관리 페이지:** 사이트 이름·아이콘·내 닉네임, 이모티콘 등록, 녹음 총용량·이번 달 예상 비용, 보안 규칙 점검, 자동 백업·JSON 내보내기
- 여럿이 동시에 고쳐도 서로 덮어쓰지 않습니다

데이터는 각자의 Firebase에 저장되고, 이 저장소에는 코드만 있습니다.

## 내 사이트 만들기 (처음 한 번, 30분쯤)

필요한 것: **GitHub 계정**, **Google 계정**

### 1. 이 저장소 포크하기
이 페이지 오른쪽 위 **Fork** → **Create fork**.
사이트 주소는 `https://내아이디.github.io/저장소이름/` 이 됩니다.

### 2. Firebase 프로젝트 만들기
1. [Firebase 콘솔](https://console.firebase.google.com)에서 **프로젝트 추가** (Google 애널리틱스는 꺼도 됩니다)
2. **빌드 → Firestore Database → 데이터베이스 만들기** (위치는 `asia-northeast3 (서울)` 추천, 프로덕션 모드)
3. **빌드 → Authentication → 시작하기 → 로그인 방법**에서 **Google**과 **익명**을 켭니다
4. **Authentication → 설정 → 승인된 도메인**에 `내아이디.github.io` 추가
5. (녹음 파일·후기 사진·이모티콘도 올리려면) **빌드 → Storage → 시작하기**
   Storage는 사용한 만큼 내는 **Blaze 요금제**여야 쓸 수 있습니다(카드 등록이 필요합니다). 대사 로그와 글 후기만 쓸 거면 이 단계는 건너뛰어도 됩니다 (녹음·사진·이모티콘 올리기만 안 됩니다).
   - **위치는 꼭 `US-EAST1`, `US-CENTRAL1`, `US-WEST1` 중 하나로 골라 주세요.** 이 세 곳만 저장 5GB가 계속 무료입니다. 서울 등 다른 위치는 처음부터 요금이 붙고, 위치는 나중에 바꿀 수 없습니다.
   - 녹음은 올릴 때 브라우저에서 말소리용 opus로 바꿔서 보통 원래 크기의 1/2~1/3로 줄여 올립니다(크롬·엣지). 녹음 한 회차가 보통 수십 MB라, 5GB면 녹음 100개 넘게 무료 범위입니다. 쓰는 양은 **⚙ 관리 → 저장 공간**에서 볼 수 있습니다.
   - 혹시 모를 요금이 걱정되면 [Google Cloud 결제 → 예산 및 알림](https://console.cloud.google.com/billing)에서 1,000원 같은 작은 예산 알림을 걸어 두세요.
6. **프로젝트 설정(톱니) → 일반 → 내 앱 → 웹 앱(`</>`) 추가** → 나오는 `firebaseConfig` 값을 메모해 둡니다

### 3. 포크한 저장소에 내 설정 넣기
포크한 저장소 → **Settings → Secrets and variables → Actions → Variables 탭 → New repository variable** 로 두 개를 만듭니다.

| Name | Value |
|---|---|
| `FIREBASE_CONFIG` | 2-6에서 메모한 값을 JSON 한 줄로 (아래 예시처럼 키에 따옴표) |
| `OWNER_EMAIL` | 관리자로 쓸 Google 이메일 |

`FIREBASE_CONFIG` 예시:
```
{"apiKey":"AIza...","authDomain":"내프로젝트.firebaseapp.com","projectId":"내프로젝트","storageBucket":"내프로젝트.firebasestorage.app","messagingSenderId":"123...","appId":"1:123...:web:abc..."}
```

### 4. 배포 켜기
1. 포크한 저장소 → **Actions** 탭 → **I understand my workflows, go ahead and enable them**
2. **Settings → Pages → Build and deployment → Source** 를 **GitHub Actions** 로
3. **Actions** 탭 → 왼쪽 **사이트 배포** → **Run workflow**
   몇 분 뒤 `https://내아이디.github.io/저장소이름/` 이 열립니다.

### 5. 관리자로 로그인하고 보안 규칙 넣기
1. 사이트 맨 아래 **관리자 로그인** → 3에서 넣은 이메일의 Google 계정으로 로그인
2. **"보안 규칙을 새 버전으로 바꿔 주세요"** 창이 뜹니다 (처음엔 꼭 뜹니다)
3. **규칙 복사** → **Firebase 규칙 화면 열기** → 원래 내용을 전부 지우고 붙여 넣기 → **게시**
   DB 규칙(Firestore)과 녹음 저장소 규칙(Storage) 두 번 합니다. 관리자 이메일은 자동으로 채워져 있습니다.
4. 사이트를 새로고침해서 **⚙ 관리 → 보안 규칙 점검**이 둘 다 **✓ 최신**이면 끝입니다!

### 6. 처음 설정
- **⚙ 관리 → 사이트 설정:** 사이트 이름·설명·아이콘, **내 닉네임**(여러 개면 쉼표로). 내 닉네임과 같은 플레이어는 세션마다 자동으로 '나'가 됩니다
- **⚙ 관리 → 이모티콘:** 이름과 이미지를 올리면 사이트 어디서든 `:이름:`으로 씁니다 (Storage 필요)
- 메인 화면 **＋ 세션 올리기**로 첫 세션을 올립니다

## 쓰는 법 요약

**세션 올리기** (메인 화면 ＋ 세션 올리기, 또는 세션 페이지의 ＋ 회차 올리기)
1. 오프라인 / 온라인
2. 이어서 하는 세션(완주한 세션은 보이지 않습니다) / 새 세션
3. 오프라인: 클로바노트 txt + 녹음 파일(이름이 같으면 알아서 짝짓습니다) 또는 녹음 없음
   온라인: 코코포리아 방 메뉴 → 로그 출력으로 받은 html 또는 로그 없음
4. 확인하고 올리기

코코포리아 로그는 줄마다 실제 시각(한국 시간)이 표시됩니다. 이 기능이 생기기 전에 올린 로그는 로그 페이지 왼쪽 아래 **🕘 코코포리아 html 다시 골라 실제 시각 넣기**로 원래 html을 한 번 다시 고르면, 같은 시나리오의 회차들에 한꺼번에 시각이 들어갑니다.

**같이 플레이한 사람에게 보내기**
세션 페이지 맨 아래 **세션 비밀번호 → 링크+비밀번호 복사**를 보냅니다. 받은 사람은 링크로 들어와 자기 인물을 고르고 비밀번호를 넣습니다. 그 다음부터 로그 고치기·후기·댓글을 쓸 수 있습니다. 비밀번호를 새로 만들면 예전 비밀번호로 연 사람은 다시 잠깁니다.

**GM에게 후기 보내기**
후기 옆 🔗을 누르면 그 후기만 보이는 링크가 복사됩니다. 이 링크는 비밀번호 없이 누구나 볼 수 있습니다.

**캠페인으로 묶기**
여러 시나리오를 이어서 가는 캠페인은 세션 수정 화면의 **캠페인** 칸에서 묶습니다(＋ 새 캠페인으로 만들기). 캠페인 페이지에서 **이미 있는 세션 넣기**로 넣어도 됩니다.
- **룰:** 캠페인 룰을 정해 두면 각 편은 룰을 비워도 캠페인 룰을 따라갑니다. 다른 룰로 간 편만 따로 적으면 그 편에만 룰 태그가 붙습니다.
- **외전:** 체크해 두면 편 번호 없이 '외전'으로 보입니다.
- **순서:** 넣은 세션은 마지막 플레이 날짜 순서로 들어갑니다. 바꾸려면 그 세션의 ✎ 수정 → 캠페인 칸의 순서에서 고릅니다.
- **다음 편:** 세션 올리기의 **캠페인의 다음 시나리오**나 캠페인 페이지의 **＋ 다음 시나리오 올리기**로 올리면 지난 편 플레이어가 미리 채워지고, 앞의 편은 자동으로 완주 처리됩니다(외전은 제외).
- **비밀번호:** 캠페인 비밀번호 하나로 모든 편이 열립니다. 캠페인 페이지 맨 아래에 있습니다.
- **보이는 곳:** 진행 중인 캠페인은 첫 화면 맨 위에 따로 보이고, 캠페인 수정에서 **캠페인 완주**를 체크하면 완주 도장이 찍혀 다른 세션들 사이에 날짜순으로 섞입니다.

**완주 처리**
세션 페이지 ✎ 수정 → 완주에 체크하면 메인 화면에 완주 도장이 찍히고, 세션 올리기의 '이어서 하는 세션' 목록에서 빠집니다.

**로그 정리 단축키** (로그 페이지와 책 고치기가 같은 규칙입니다. 로그 페이지에서 `?`를 누르면 전체 표가 나옵니다)
- **고르기:** 클릭 · Shift+클릭 또는 줄 위로 드래그(여러 줄) · ↑↓
- **고치기:** 더블클릭 또는 Enter로 시작 → Enter 저장 · Shift+Enter 줄바꿈 · Esc 취소
- **화자:** 1~9 (왼쪽 목록 순서) · 0 전원. 여러 줄도 한 번에 바뀝니다
- **책에 넣기:** C 잡담 · X 빼기 · B 여기서 본세션 시작
- **넣기·정리:** N 상황 묘사 · D 주사위 · H 핸드아웃 · S 단락(단락을 고르고 누르면 대→중→하) · M 위 줄과 합치기 · Delete 지우기 · Ctrl+Z 되돌리기
- **글자 드래그:** 한 줄 안의 글자를 드래그하면 떼어서 다른 대사로 · 상황 묘사로 떼기 · 고유명사로 바꾸기 메뉴가 뜹니다
- 한글 입력 상태에서도 같은 자리 키로 됩니다

**리플레이북 만들기**
세션 페이지의 **📖 리플레이북**을 누르면 그 세션의 모든 회차가 책 한 권으로 정리됩니다. 표지 · 등장인물 · 차례 · 본문 · 플레이어 후기 순서입니다. 세션 비밀번호로 들어온 사람은 누구나 보고 고칠 수 있습니다.
- **판형:** A5가 기본이고 B6, A6 문고를 고를 수 있습니다. **PDF로 저장 · 인쇄**를 누르고 인쇄 창에서 'PDF로 저장'을 고르면 됩니다.
- **본세션 시작:** 책은 본세션 시작 줄부터 들어갑니다. 코코포리아 로그는 메인 채널의 첫 대사가 기본값입니다. 바꾸려면 로그 페이지에서 줄 오른쪽의 ▶를 누르거나, 책 고치기에서 줄을 누르고 **▶ 여기서 시작**을 고릅니다. 시작 줄 앞은 따로 고르지 않으면 **빼기**로 처리되고, 로그에서도 흐리게 보입니다. 그중 넣고 싶은 줄만 책 고치기에서 1(본문)이나 2(잡담)로 바꾸면 됩니다.
- **장 나누기:** 장은 단락으로만 나뉩니다. 큰 단락이 장이 되고 작은 단락은 장 안의 소제목으로 들어가며, 둘 다 차례에 나옵니다. 회차 날짜는 각 쪽 아래에 표시됩니다. 상황 묘사는 지문으로 들어갑니다.
- **대사:** 적은 그대로 들어갑니다. 「」 안은 대사로, 「」 밖은 행동 묘사로 조금 옅게 보입니다. 사이트가 「」를 자동으로 붙이지는 않습니다.
- **책 고치기:** 줄을 고르고 **C**(잡담) · **X**(빼기)를 누릅니다. 한 번 더 누르면 본문으로 돌아갑니다. Shift+클릭이나 줄 위로 드래그해서 여러 줄을 한 번에 고를 수 있고, 단락 머리의 **이 단락 통째로 빼기**로 단락을 통째로 뺄 수 있습니다. 잡담은 책에 플레이어 이름과 함께 작은 회색 글씨로 들어가고, 빼기는 책에 나오지 않습니다. 줄을 두 번 누르면 글을 고칠 수 있고, 고친 글은 로그에도 그대로 반영됩니다.
- **로그 페이지에서는:** 잡담으로 정한 줄은 이름과 한 줄로 회색으로, 뺀 줄은 흐리게 보입니다. 코코포리아의 잡담 채널은 따로 정하지 않아도 잡담으로 처리됩니다.
- **등장인물 소개 · 고유명사 설명:** 책 고치기 화면 맨 위에서 적습니다. 고유명사 설명은 로그 페이지 고유명사 목록에서도 고칠 수 있고, 설명이 있는 낱말은 처음 나오는 쪽 여백에 메모로 붙습니다.

**그 밖에 세션 수정 화면에서 할 수 있는 것**
- **녹음 없이 플레이한 날:** 녹음이 금지된 날을 날짜만 회차로 추가합니다
- **공유 이미지:** 링크를 보낼 때 카톡·디스코드 미리보기에 뜨는 그림(1200×630)
- **플레이어 · 등장인물:** 인장, 캐릭터 이름, GM 지정, 순서 바꾸기, 대사 없는 플레이어 지우기
- **다른 세션과 합치기:** 실수로 두 개가 된 세션을 하나로 합칩니다

## 업데이트 받기

원본 사이트가 업데이트되면 **⚙ 관리** 아이콘에 빨간 점이 생깁니다.

1. **⚙ 관리 → 업데이트**에서 바뀐 내용을 확인하고 **업데이트하러 가기**
2. 열리는 내 저장소 페이지에서 **Sync fork → Update branch**
3. 몇 분 뒤 자동으로 다시 배포됩니다

보안 규칙이 바뀐 업데이트라면 관리자로 들어왔을 때 규칙 안내 창이 다시 뜹니다. 5-3처럼 붙여 넣고 게시하면 됩니다.

> 포크한 저장소의 파일은 직접 고치지 않는 것이 좋습니다. 고치면 업데이트할 때 충돌이 날 수 있습니다. 개인 설정은 전부 Variables와 DB에 있어서 파일을 고칠 일이 없습니다.

## 자주 묻는 것

- **비밀번호 없이 로그가 보이지 않나요?** 로그·녹음·핸드아웃·댓글은 Firebase 서버 규칙으로 잠겨 있어서, 비밀번호를 넣은 사람과 관리자만 볼 수 있습니다. 세션 이름·룰·개요·캐릭터 이름은 목록에 보이도록 공개입니다.
- **후기는 공개인가요?** 후기는 GM에게 링크로 보낼 수 있게 누구나 읽을 수 있습니다. 링크 후기에 적은 글 비밀번호 메모도 마찬가지이니, 다른 곳에도 쓰는 중요한 비밀번호는 적지 마세요. 후기를 쓰는 것은 세션 비밀번호로 들어온 사람만 가능합니다.
- **'나'를 잘못 골랐습니다.** 세션 페이지 등장인물 칸의 **바꾸기**로 다시 고르면 됩니다. '나'는 브라우저마다 따로 기억하기 때문에, 다른 기기에서는 다시 골라야 합니다.
- **다른 기기에서 내가 쓴 후기·댓글을 고칠 수 없습니다.** 후기·댓글은 쓴 브라우저에서만 고칠 수 있습니다. 관리자는 어디서든 고치고 지울 수 있으니 관리자에게 부탁해 주세요.
- **외부인으로 들어오면 무엇이 다른가요?** 로그·후기·댓글을 읽기만 할 수 있습니다. 화면에서만 막는 방식이라, 같이 플레이한 사람끼리 비밀번호를 나누는 것을 전제로 합니다.
- **저장소가 공개인데 괜찮나요?** 저장소에는 코드만 있습니다. Firebase 접속 값(apiKey)은 원래 공개돼도 되는 값이고, 실제 보호는 서버 규칙이 합니다.
- **링크 미리보기 이미지가 바뀌지 않습니다.** 30분마다 자동 배포될 때 반영됩니다. 카카오톡은 미리보기를 한동안 저장해 두기 때문에 더 늦을 수 있습니다.
- **배포가 실패했습니다.** GitHub 쪽 일시 장애일 때가 많습니다(배포는 실패하면 알아서 두 번 더 시도합니다). 그래도 실패하면 몇 분 뒤 **Actions → 사이트 배포 → Run workflow**로 다시 돌려 주세요.
- **요금이 나오지는 않나요?** Firestore(대사·후기·댓글)는 소규모 모임이면 무료 사용량 안입니다. 녹음은 Storage 위치를 US 세 곳 중 하나로 골랐다면 5GB까지 무료이고, 듣기(내려받기)도 월 100GB까지 무료입니다. **⚙ 관리 → 저장 공간**에서 이번 달 예상 비용을 볼 수 있습니다.
- **녹음을 줄이면 음질이 나빠지지 않나요?** 말소리에 맞춘 opus(모노 24kbps)라 대사를 듣는 데는 차이를 거의 못 느낍니다. 크롬·엣지에서 올릴 때만 줄이고, 지원하지 않는 브라우저이거나 별로 줄지 않으면 원본을 그대로 올립니다. 끄려면 **⚙ 관리 → 사이트 설정**에서 '녹음을 올릴 때 용량 줄이기'를 해제하세요. 이미 올린 녹음은 바뀌지 않습니다.
- **데이터가 날아가면 어떡하나요?** 관리자가 사이트에 들어오면 일주일에 한 번 전체 데이터(세션·대사·캠페인·캠프·후기·댓글·비밀번호)를 JSON으로 Storage에 자동 백업하고, 최근 8개를 남겨 둡니다. **⚙ 관리 → 백업 · 옮기기**에서 **받기**로 내려받은 뒤 **JSON 가져오기**로 되살리면 됩니다. 녹음 파일은 백업에 들어가지 않습니다. (Storage를 켜지 않았다면 자동 백업도 되지 않으니, 가끔 **JSON으로 내보내기**로 직접 받아 두세요.)
- **보안 점검을 직접 돌려 보고 싶습니다.** **Actions → 보안 점검 (수동) → Run workflow**를 누르면, 비밀번호 없는 사람이 로그를 읽을 수 있는지 서버에 직접 물어보고 결과를 보여 줍니다.
